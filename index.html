VoiceMeeter IdleWatcher

Automatic VoiceMeeter shutdown with a strict safety rule: the idle threshold must be reached and the display must be fully off.

Purpose

What it does

IdleWatcher watches Windows inactivity and display power state. When both safety conditions are met, it sends a shutdown request through the VoiceMeeter Remote API.

Idle-aware

Checks how long Windows has been inactive. The default threshold is 8 minutes and can be configured from 1 to 60 minutes.

Display-aware

Uses Windows display power notifications. A darkened or unknown display state is not treated as fully off.

VoiceMeeter-aware

Uses the Remote API and keeps monitoring if the VoiceMeeter engine is not running.

Safety first

Two conditions. Both must be true.

The display state is a hard safety gate. Idle time alone can never trigger automatic shutdown.

✓ Display Off (0) + idle threshold reached

The watcher performs a final re-check and may send the shutdown command.

× Display On (1) or Dimmed (2)

Automatic shutdown is blocked, even when the idle threshold has elapsed.

× Unknown display state

Uncertainty means no shutdown. The watcher keeps monitoring.

Stopping IdleWatcher stops the automation process. It does not itself shut down VoiceMeeter.

How the watcher makes its decision

Getting started

Quick start

The published release is distributed as source files. There is no separate installer or executable package.

Download

Get the v1.0.1 source ZIP from the button at the top of this page.

Extract

Unpack the archive. Keep VoiceMeeter-IdleWatcher.ps1 and VoiceMeeter-IdleWatcher.vbs in the same folder.

Start

Double-click VoiceMeeter-IdleWatcher.vbs. The watcher starts PowerShell hidden.

Stop

Send the graceful stop request from the same folder:

wscript.exe VoiceMeeter-IdleWatcher.vbs /stop
Compatibility

Requirements

  • Windows.
  • Windows PowerShell 5.1.
  • VoiceMeeter installed.
  • The matching VoiceMeeter Remote API DLL.
  • Windows Script Host enabled for the VBS launcher.
Optional MacroButtons indicator

The watcher can synchronize a MacroButtons visual state through Remote API STATEONLY mode. This changes the displayed state without executing the button macro. If MacroButtons synchronization is unavailable, the main watcher continues to work.

VoiceMeeter IdleWatcher

Автоматическое выключение VoiceMeeter с жёстким правилом безопасности: должен истечь заданный порог бездействия, а дисплей должен быть полностью выключен.

Последний опубликованный релиз: v1.0.1 Windows PowerShell 5.1
Скачать исходники ZIP · v1.0.1 Примечания к релизу Репозиторий GitHub

Что делает программа

IdleWatcher следит за временем бездействия Windows и состоянием питания дисплея. Когда одновременно выполнены оба условия безопасности, утилита отправляет команду на выключение VoiceMeeter через Remote API.

Контроль бездействия

Порог по умолчанию: 8 минут. Его можно настроить в диапазоне от 1 до 60 минут.

Контроль дисплея

Используются системные уведомления Windows. Затемнённый или неизвестный статус не считается выключенным экраном.

Контроль VoiceMeeter

Работа идёт через Remote API. Если движок VoiceMeeter не запущен, наблюдатель продолжает мониторинг.

Два условия. Оба обязательны.

✓ Дисплей Off (0) + истёк порог бездействия

Перед отправкой команды выполняется финальная повторная проверка.

× Дисплей On (1) или Dimmed (2)

Автоматическое выключение заблокировано, даже если компьютер давно бездействует.

× Состояние дисплея неизвестно

Неопределённость означает запрет выключения. Наблюдатель продолжает работу.

Остановка IdleWatcher завершает только саму утилиту. Она не выключает VoiceMeeter.

Как принимается решение

Упрощённая схема реального потока работы. Непосредственно перед командой отключения порог бездействия и состояние дисплея проверяются ещё раз.

Быстрый запуск

Скачать

Скачайте ZIP с исходниками версии v1.0.1 по кнопке выше.

Распаковать

Файлы VoiceMeeter-IdleWatcher.ps1 и VoiceMeeter-IdleWatcher.vbs должны лежать в одной папке.

Запустить

Дважды щёлкните VoiceMeeter-IdleWatcher.vbs. PowerShell запустится в скрытом режиме.

Остановить

Выполните команду штатной остановки из той же папки:

wscript.exe VoiceMeeter-IdleWatcher.vbs /stop

Требования

  • Windows.
  • Windows PowerShell 5.1.
  • Установленный VoiceMeeter.
  • Подходящая DLL VoiceMeeter Remote API.
  • Включённый Windows Script Host для VBS-запускателя.
Необязательный индикатор MacroButtons

Наблюдатель может синхронизировать отображаемое состояние кнопки через режим Remote API STATEONLY. Он меняет только индикацию, не запуская макрос. Недоступность MacroButtons не мешает основной работе наблюдателя.
