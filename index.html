Open-source Windows utility

VoiceMeeter IdleWatcher

Automatic VoiceMeeter shutdown, governed by two conditions: Windows user inactivity and the display being fully off.

View source on GitHub Latest release Documentation

What it does

VoiceMeeter IdleWatcher is a Windows PowerShell automation tool. It monitors the Windows idle timer and display power state, then requests VoiceMeeter shutdown through the VoiceMeeter Remote API only when the configured idle threshold has elapsed and the display is fully off.

  • Checks Windows user idle time.
  • Tracks display power notifications.
  • Allows shutdown only when the display state is Off (0) and the idle threshold is reached.
  • Blocks shutdown while the display is On, Dimmed, or in an unknown state.
  • Supports graceful stop, single-instance protection, and primary/fallback/emergency logging.

Safety behavior

The display state is a hard safety gate, not just an additional idle hint.

  • Display Off + idle threshold reached: shutdown is permitted.
  • Display On or Dimmed: shutdown is blocked.
  • Unknown display state: shutdown is blocked.

Stopping IdleWatcher stops the automation process. It does not itself shut down VoiceMeeter.

Requirements

  • Windows and Windows PowerShell 5.1.
  • VoiceMeeter installed.
  • The matching VoiceMeeter Remote API DLL.
  • Windows Script Host for the optional VBS launcher.

The default idle threshold is 8 minutes. The script parameter accepts values from 1 to 60 minutes.

Source code and documentation

The project is maintained in a public GitHub repository under the MIT License. The repository contains the PowerShell watcher, hidden VBS launcher, English and Russian documentation, architecture notes, changelog, and automated Windows PowerShell 5.1 checks.

Русская версия

VoiceMeeter IdleWatcher

Небольшая утилита для Windows на PowerShell, которая отслеживает время бездействия пользователя и состояние питания дисплея. Команда выключения VoiceMeeter отправляется только тогда, когда одновременно выполнены два условия: достигнут заданный порог бездействия и дисплей полностью выключен.

  • Дисплей выключен (Off) и порог бездействия достигнут: выключение разрешено.
  • Дисплей включён (On) или затемнён (Dimmed): выключение заблокировано.
  • Состояние дисплея неизвестно: выключение заблокировано.

Остановка IdleWatcher завершает только саму утилиту и не закрывает VoiceMeeter.
